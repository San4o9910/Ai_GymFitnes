# Ai GymFitnes — «СпортФорма»

Персональное мобильное PWA-приложение с 12-недельной программой тренировок, расписанием, дневником рабочих весов и контролем прогресса.

## Что реализовано

- расписание тренировок на понедельник, среду, четверг и дополнительную субботу;
- полный и облегчённый режим тренировки;
- проверка сна, энергии и физической нагрузки перед занятием;
- пошаговые карточки упражнений;
- подсказки по технике, частые ошибки и безопасные замены;
- ввод веса, повторений и выполненных подходов;
- таймер отдыха;
- график изменения веса;
- история тренировок;
- экспорт и импорт прогресса в JSON;
- офлайн-режим после первого открытия;
- установка на телефон как PWA.

## Быстрый запуск

### Linux / macOS

```bash
chmod +x start.sh
./start.sh
```

### Windows

Запустите `start.bat`.

### Через Python вручную

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

> Не открывайте `index.html` напрямую через `file://`: офлайн-режим и установка PWA требуют HTTP или HTTPS.

## Публикация через GitHub Pages

В репозитории есть workflow `.github/workflows/pages.yml`.

1. Откройте **Settings → Pages**.
2. В поле **Source** выберите **GitHub Actions**.
3. Запустите workflow **Deploy GitHub Pages** во вкладке **Actions**, если он не запустился автоматически.

После публикации адрес будет таким:

`https://san4o9910.github.io/Ai_GymFitnes/`

## Структура

```text
.
├── index.html                  # Главная страница
├── loader.js                   # Загружает и объединяет код приложения
├── app-parts/                  # Логика приложения и программа тренировок
│   ├── part00.txt
│   ├── ...
│   └── part06.txt
├── styles.css                  # Интерфейс и адаптивная верстка
├── sw.js                       # Офлайн-кэш
├── manifest.webmanifest        # PWA-манифест
├── assets/icon.svg             # Иконка приложения
├── start.sh                    # Локальный запуск Linux/macOS
├── start.bat                   # Локальный запуск Windows
└── .github/workflows/          # Автоматизация и GitHub Pages
```

Код приложения разделён на несколько текстовых частей. `loader.js` загружает их по порядку, объединяет и запускает как единый файл. Это не влияет на работу интерфейса.

## Хранение данных

Прогресс сохраняется локально в браузере устройства. В разделе «Данные» можно скачать резервную копию и импортировать её обратно.

## Открытые источники примеров упражнений

- [wger](https://github.com/wger-project/wger) — открытый проект и база упражнений;
- [Wikimedia Commons](https://commons.wikimedia.org/) — свободно лицензированные изображения и материалы.

В приложении используются собственные схематичные подсказки. В карточках упражнений есть ссылки на открытые источники для дополнительных примеров техники.

## Важно

Приложение помогает следовать составленной программе, но не заменяет врача или очного тренера. При боли в груди, обмороке, необычной одышке, острой боли или повторяющемся головокружении тренировку следует остановить и обратиться за медицинской оценкой.
