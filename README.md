# Ai GymFitnes — «СпортФорма»

Персональное мобильное PWA-приложение с 12-недельной программой тренировок, расписанием, дневником рабочих весов и контролем прогресса.

![Превью приложения](docs/sportforma-preview.png)

## Что уже реализовано

- расписание тренировок на понедельник, среду, четверг и дополнительную субботу;
- полный и облегчённый режим тренировки;
- проверка сна, энергии и физической нагрузки перед занятием;
- пошаговые карточки упражнений, техника, ошибки и безопасные замены;
- ввод веса, повторений и выполненных подходов;
- таймер отдыха;
- дневник веса и тренировочного прогресса;
- экспорт и импорт данных в JSON;
- офлайн-режим после первого открытия;
- установка на телефон как PWA.

## Быстрый запуск

### Linux / macOS

```bash
chmod +x start.sh
./start.sh
```

### Windows

Запустите `start.bat`.

### Через Python вручную

```bash
python -m http.server 8080
```

Откройте в браузере `http://localhost:8080`.

> Не открывайте `index.html` напрямую через `file://`: service worker и полноценный PWA-режим требуют HTTP или HTTPS.

## GitHub Pages

В репозитории добавлен workflow `.github/workflows/pages.yml`. После первого push:

1. Откройте **Settings → Pages**.
2. В поле **Source** выберите **GitHub Actions**.
3. Дождитесь завершения workflow **Deploy GitHub Pages**.

После этого приложение будет доступно по адресу:

`https://san4o9910.github.io/Ai_GymFitnes/`

## Структура

```text
.
├── index.html                  # Главная страница PWA
├── app.js                      # Логика приложения и программа тренировок
├── styles.css                  # Интерфейс и адаптивная верстка
├── sw.js                       # Офлайн-кэш
├── manifest.webmanifest        # PWA-манифест
├── assets/icon.svg             # Иконка
├── standalone/                 # Однофайловая версия
├── docs/                       # Превью
├── downloads/                  # Готовый архив PWA
└── .github/workflows/pages.yml # Публикация на GitHub Pages
```

## Хранение данных

Прогресс сохраняется локально в браузере устройства. В разделе «Данные» можно экспортировать резервную копию и импортировать её обратно.

## Открытые источники примеров упражнений

- [wger](https://github.com/wger-project/wger) — открытый проект и база упражнений;
- [Wikimedia Commons](https://commons.wikimedia.org/) — свободно лицензированные изображения и материалы.

В приложении используются собственные схематичные подсказки, а в карточках упражнений добавлены ссылки на открытые источники для дополнительных примеров техники.

## Важно

Приложение помогает следовать составленной программе, но не заменяет врача или очного тренера. При боли в груди, обмороке, необычной одышке, острой боли или повторяющемся головокружении тренировку следует остановить и обратиться за медицинской оценкой.
